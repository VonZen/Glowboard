# Glowboard Web 启动页

更新：2026-10-15

## 目标

将品牌占位页扩展为正式产品启动页，展示 Glowboard 的使用场景、萌宠主题和 Pro 功能，提供 App Store 下载入口及浏览器互动预览。继续使用仓库 VonZen/Glowboard 与 GitHub Pages，保留 App 已配置的两份协议地址。

## 页面范围

- 英文首页延续现有网站默认语言；使用 App 当前奶油配色和 I❤️U 小狗图标，三主题预览覆盖小狗、小猫、柴犬。
- 首屏：产品定位、App Store 入口、萌宠与实时灯牌。
- 场景：演唱会、告白、生日、接机，点选后将文案和配色带入预览。
- 互动预览：最多 40 个 UTF-16 单位的输入，三种颜色，LED／霓虹／高清大字三种风格，滚动暂停／继续。暂停和减少动态效果时完整缩放显示长文案。
- 主题：奶油、蜜桃、星光；可切换页面配色与首屏宠物，不保存选择，不改变输入文案。
- Pro：额外灯珠／动效／渐变、声音响应、导出 MP4／GIF。不写死价格、试用资格或未实现的云端功能。
- 常见问题、联系入口、隐私政策及用户协议。按用户指示不制作上线状态、即将上线标记或发布时间说明；下载入口沿用 App 配置中的 id6822701782。

## 技术与素材

保留原生 HTML、CSS 和轻量 JavaScript，无依赖和框架迁移。Web 预览是独立浏览器效果，不声称是 App 截图或完整原生渲染器。美术全部来自当前 App，来源见 assets.md，不使用模拟器。

Canvas 点阵只在文字、尺寸、样式或颜色变化时生成，滚动仅移动缓存图像；非可见区域和后台标签停止刷新。无远程字体、分析脚本、Cookie、本地存储、录音或上传。用户输入只作为文字处理，不解释为 HTML 或脚本。

仅部署 public/。原生 App 工程、购买和统计配置不在本次修改范围。协议同步说明浏览器预览，地址不变。

## 验收

- 桌面、平板和手机可读，无横向溢出；输入框字号避免 iOS 自动放大。
- 输入、预设、配色、模式、主题和滚动暂停正常；主题切换保留文案。
- 尊重减少动态效果；无 JavaScript 时产品、美术、下载和协议链接仍可访问。
- 静态检查覆盖发布文件、链接／锚点、元数据、站点地图及脚本无网络／持久化接口。
- 推送现有仓库并通过 GitHub Pages 工作流更新网站。
